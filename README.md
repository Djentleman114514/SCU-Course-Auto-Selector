# SCU Course Monitor

四川大学自由选课页面的自动选课脚本，面向四川大学学生使用。

项目的功能变更、关键规则和测试结论见 [CHANGELOG.md](CHANGELOG.md)。

## 脚本入口（v1.0）

直接打开仓库根目录的 [scu-course-monitor.user.js](./scu-course-monitor.user.js)，复制全部内容到自由选课页面的浏览器 Console 运行，或作为 Tampermonkey 用户脚本安装。

## 当前版本

v1.0 会开启“有课余量的课程”筛选，并按输入顺序轮询。输入课程号后可选填课序号：留空时该课程号下任意有余量班次均可；填写如 `01` 时只选择对应班次。发现第一门匹配且有余量的课程后会自动勾选并提交，然后停止。

## 使用前须知

运行脚本前，请先登录四川大学选课系统，进入**自由选课**界面，并勾选**“有课余量的课程”**，课程类别选择**"全部"**。

随后打开浏览器开发者工具的 **Console（控制台）**。不同系统和主流浏览器的打开方式如下：

### Windows

| 浏览器             | 打开 Console 的方式                                              |
| --------------- | ----------------------------------------------------------- |
| Google Chrome   | 按 `Ctrl + Shift + J`；也可按 `F12` 打开开发者工具后选择 **Console**       |
| Microsoft Edge  | 按 `Ctrl + Shift + J`；也可按 `F12` 打开开发者工具后选择 **Console**       |
| Mozilla Firefox | 按 `Ctrl + Shift + K`；也可按 `F12` 打开开发者工具后选择 **控制台 / Console** |

### macOS

| 浏览器             | 打开 Console 的方式                                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Google Chrome   | 按 `Command + Option + J`                                                                                                                       |
| Microsoft Edge  | 按 `Command + Option + J`                                                                                                                       |
| Mozilla Firefox | 按 `Command + Option + K`                                                                                                                       |
| Safari          | 首次使用需在 **Safari → 设置 → 高级** 中启用网页开发者相关选项，然后按 `Command + Option + C` 打开 JavaScript 控制台；也可以按 `Command + Option + I` 打开网页检查器后选择 **控制台 / Console** |

打开 Console 后，将仓库根目录 `scu-course-monitor.user.js` 中的完整代码复制进去运行即可。

## 使用方法

打开自由选课页面后，完整复制根目录 `scu-course-monitor.user.js` 到浏览器 Console ，按下**"Enter"**即开始运行。脚本会逐个弹窗询问课程号；每门课程随后可选填课序号（如 `01`），留空则接受该课程号下任意班次。首次输入后，待选课程会保存在当前浏览器标签页；成功选中一门后脚本自动移除它，回到自由选课页面再次运行(即再次粘贴代码到控制台)即可继续剩余课程。

如果需要重新输入别的课程号，在控制台中输入reset()后按**"Enter"**，重新把脚本复制进去即可。
