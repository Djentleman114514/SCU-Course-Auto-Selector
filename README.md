# SCU Course Auto Selector

四川大学自由选课页面的自动选课脚本，面向四川大学学生使用。

项目的功能变更、关键规则和测试结论见 [CHANGELOG.md](CHANGELOG.md)。

## 脚本入口（v1.1）

直接打开仓库根目录的 [scu-course-monitor.user.js](./scu-course-monitor.user.js)，复制全部内容到自由选课页面的浏览器 Console 运行。

## 当前版本

v1.1 会自动开启**有课余量的课程**筛选，并按输入顺序轮询。输入课程号后可选填课序号：留空时，该课程号下任意有余量班次均可；填写如 `01` 时，只选择对应课序号的班次。发现按输入顺序第一门匹配且有余量的课程后，脚本会自动勾选并提交；成功后会移除该课程并继续监控剩余课程，全部完成后停止。

## 使用前须知

运行脚本前，请先登录四川大学选课系统，进入**自由选课**界面，并将课程类别选择为**全部**。脚本会自动开启**有课余量的课程**筛选。

随后打开浏览器开发者工具的 **Console（控制台）**。不同系统和主流浏览器的打开方式如下：

### Windows

| 浏览器 | 打开 Console 的方式 |
| --- | --- |
| Google Chrome | 按 `Ctrl + Shift + J`；也可按 `F12` 打开开发者工具后选择 **Console** |
| Microsoft Edge | 按 `Ctrl + Shift + J`；也可按 `F12` 打开开发者工具后选择 **Console** |
| Mozilla Firefox | 按 `Ctrl + Shift + K`；也可按 `F12` 打开开发者工具后选择 **控制台 / Console** |

### macOS

| 浏览器 | 打开 Console 的方式 |
| --- | --- |
| Google Chrome | 按 `Command + Option + J` |
| Microsoft Edge | 按 `Command + Option + J` |
| Mozilla Firefox | 按 `Command + Option + K` |
| Safari | 首次使用需在 **Safari → 设置 → 高级** 中启用网页开发者相关选项，然后按 `Command + Option + C` 打开 JavaScript 控制台；也可以按 `Command + Option + I` 打开网页检查器后选择 **控制台 / Console** |

打开 Console 后，将仓库根目录 `scu-course-monitor.user.js` 中的完整代码复制进去运行即可。

## 使用方法

打开自由选课页面后，完整复制根目录 `scu-course-monitor.user.js` 到浏览器 Console，按 **Enter** 即开始运行。

脚本会逐个弹窗询问课程号；每门课程随后可选填课序号，例如 `01`。课序号留空则接受该课程号下任意有余量的班次。

首次输入后，待选课程会保存在当前浏览器标签页。成功选中一门后，脚本会自动移除该课程，并在原选课页继续监控剩余课程，无需再次粘贴脚本。

如果选课结果在新标签页打开，可直接查看结果，原“选课”标签页会继续运行。如果用户手动刷新、关闭或完整跳转了原选课页，Console 注入的脚本会消失，此时仍需重新运行。

如系统要求验证码，脚本会在勾选目标课程后暂停。请填写验证码并手动提交。

脚本启动后，页面右下角会显示**“重新选择课程”**按钮。点击后可直接重新输入待选课程并继续监控，无需输入控制台命令或重新粘贴脚本。如未输入新课程，原待选列表会保留。

原有的 `reset()` 命令仍保留，可用于清空已保存的课程并停止脚本。

## 查询频率与异常处理

脚本始终串行查询，同一时间只允许一个查询请求在途。每次查询必须等待页面的真实 AJAX 响应；如果服务器响应快于 1.8 秒，脚本会继续等待至满 1.8 秒后才查询下一门。一轮结束后额外休息 5 秒。

查询超时、网络失败、HTTP `401`/`403`/`429`、登录失效或无法确认页面查询请求时，脚本会暂停，不会持续重试。脚本不绕过验证码，也不包含伪装浏览器或规避检测的逻辑。

脚本使用已登录的官方教务页面，不会将账号密码发送到第三方服务器。但学校未公开具体的请求限频阈值或自动脚本使用规则，长时间运行仍可能触发服务器限制，不建议使用真实账号测试风控阈值。
