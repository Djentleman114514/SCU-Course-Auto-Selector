# SCU Course Monitor

四川大学自由选课页面的课余量监控脚本，面向四川大学学生使用。

项目的功能变更、关键规则和测试结论见 [CHANGELOG.md](CHANGELOG.md)。

## 当前版本

当前分支 `basic-course-flow` 是“基础选课流程版”：脚本开启“有课余量的课程”筛选，按 `courseNumbers` 的填写顺序轮询；发现第一门有余量课程后会自动勾选并提交，然后停止。它不做课程时间分组。

## 使用前须知

- 仅支持四川大学当前选课系统的页面结构；页面改版后可能需要更新脚本。
- 使用者必须先自行登录，并在“自由选课”页面运行。
- 用户只需填写课程号；课序号、课程名称和课余量由页面自动读取。
- 不要把账号、密码、Cookie、Token 或个人配置提交到 GitHub。
- 请遵守学校规定、网站服务条款和合理请求频率；本项目不绕过验证码、登录限制或访问控制。
- 脚本不保证选课成功，发现余量后仍需以网页最终结果为准。

## 配置

打开 `src/scu-course-monitor.user.js`，只修改文件顶部带有 `👇` 标识的空白区域。每行填写一个**课程号**，例如 `105267020`；不要填写课序号（例如 `01`），也不需要引号或逗号：

```js
courseNumbers: `
106588020
502799010
`
```

不需要引号、逗号或修改注释。课序号、课程名称、课余量与上课时间均由页面自动读取。独立模板也见 `config.example.js`。

## 运行

当前版本可以直接把 `src/scu-course-monitor.user.js` 的内容复制到四川大学自由选课页面的浏览器 Console 中运行。它会自动开启“有课余量的课程”筛选。成功选到一门后，请手动从脚本顶部的 `courseNumbers` 删除该课程号，再重新运行脚本继续监控。脚本头部的 `@match` 需要根据实际选课域名进一步收紧后，才能作为 Tampermonkey 脚本使用。

控制命令：

```js
stopCourseMonitor()
courseMonitorStatus()
resumeCourseMonitor()
```

## 解析测试

在真正使用前，可先在自由选课页面查询任意课程，再把 `tests/parse-course-metadata.console.js` 的内容复制到浏览器 Console 运行。它只读取当前课程表格，打印课程号、课序号、课余量、周次、星期与节次，并展示按同一天内“节次区间重叠”得到的自动分组；不会查询、勾选或提交课程。

如需批量验证一组课程的分类结果，可运行 `tests/classify-course-numbers.console.js`。该脚本会确认并自动关闭“有课余量的课程”筛选，以取得完整班次；它会依次查询指定课程号，但不会勾选或提交课程。
