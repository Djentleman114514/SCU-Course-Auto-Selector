# SCU Course Monitor

四川大学自由选课页面的课余量监控脚本，面向四川大学学生使用。

## 当前版本

当前版本以“只提醒”为目标：轮询指定课程，发现课余量后弹窗并停止监控。自动勾选和提交尚未并入这个初始版本。

## 使用前须知

- 仅支持四川大学当前选课系统的页面结构；页面改版后可能需要更新脚本。
- 使用者必须先自行登录，并在“自由选课”页面运行。
- 课程号、课序号和课程时间需要使用者自己填写。
- 不要把账号、密码、Cookie、Token 或个人配置提交到 GitHub。
- 请遵守学校规定、网站服务条款和合理请求频率；本项目不绕过验证码、登录限制或访问控制。
- 脚本不保证选课成功，发现余量后仍需以网页最终结果为准。

## 配置

复制 `config.example.js` 为 `config.js`，按页面显示填写课程：

```js
{ kch: "106588020", kxh: "01", name: "巴蜀文化" }
```

不同时间段请放在不同分组。

## 运行

当前版本可以直接把 `src/scu-course-monitor.user.js` 的内容复制到四川大学自由选课页面的浏览器 Console 中运行。脚本头部的 `@match` 需要根据实际选课域名进一步收紧后，才能作为 Tampermonkey 脚本使用。

控制命令：

```js
stopCourseMonitor()
courseMonitorStatus()
resumeCourseMonitor()
```
