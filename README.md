# SCU Course Monitor

四川大学自由选课页面的课余量监控脚本，面向四川大学学生使用。

项目的功能变更、关键规则和测试结论见 [CHANGELOG.md](CHANGELOG.md)。

## 脚本入口（v1.0）

直接打开仓库根目录的 [scu-course-monitor.user.js](./scu-course-monitor.user.js)，复制全部内容到自由选课页面的浏览器 Console 运行，或作为 Tampermonkey 用户脚本安装。

## 当前版本

v1.0 会开启“有课余量的课程”筛选，并按输入顺序轮询。输入课程号后可选填课序号：留空时该课程号下任意有余量班次均可；填写如 `01` 时只选择对应班次。发现第一门匹配且有余量的课程后会自动勾选并提交，然后停止。

## 使用前须知

- 仅支持四川大学当前选课系统的页面结构；页面改版后可能需要更新脚本。
- 使用者必须先自行登录，并在“自由选课”页面运行。
- 用户不需要修改代码中的课程配置；运行后按弹窗提示逐门输入课程号，并可选择填写课序号。课程名称和课余量由页面自动读取。
- 不要把账号、密码、Cookie、Token 或个人配置提交到 GitHub。
- 请遵守学校规定、网站服务条款和合理请求频率；本项目不绕过验证码、登录限制或访问控制。
- 脚本不保证选课成功，发现余量后仍需以网页最终结果为准。

## 配置

打开自由选课页面后，完整复制根目录 `scu-course-monitor.user.js` 到浏览器 Console 运行。脚本会逐个弹窗询问课程号；每门课程随后可选填课序号（如 `01`），留空则接受该课程号下任意班次。首次输入后，待选课程会保存在当前浏览器标签页；成功选中一门后脚本自动移除它，回到自由选课页面再次运行即可继续剩余课程。

## 运行

当前版本可以直接把根目录 `scu-course-monitor.user.js` 的内容复制到四川大学自由选课页面的浏览器 Console 中运行。它会自动开启“有课余量的课程”筛选。成功选到一门后，重新运行脚本即可继续监控剩余课程。脚本头部的 `@match` 需要根据实际选课域名进一步收紧后，才能作为 Tampermonkey 脚本使用。

控制命令：

```js
stopCourseMonitor()
courseMonitorStatus()
resumeCourseMonitor()
resetCourseMonitorProgress()
```

重新输入课程时，推荐使用更简短的：

```js
reset()
```

`resetCourseMonitorProgress()` 仍可使用。

## 解析测试

在真正使用前，可先在自由选课页面查询任意课程，再把 `tests/parse-course-metadata.console.js` 的内容复制到浏览器 Console 运行。它只读取当前课程表格，打印课程号、课序号、课余量、周次、星期与节次，并展示按同一天内“节次区间重叠”得到的自动分组；不会查询、勾选或提交课程。

如需批量验证一组课程的分类结果，可运行 `tests/classify-course-numbers.console.js`。该脚本会确认并自动关闭“有课余量的课程”筛选，以取得完整班次；它会依次查询指定课程号，但不会勾选或提交课程。
